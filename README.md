# ZADEN | زَادَن — MVP 1.0 (Android build-fixed)

نسخة Flutter أولية بأربع ميزات أساسية:
1. الرئيسية واكتشاف المتاجر والمنتجات
2. البحث والتصنيفات
3. السلة وتأكيد الطلب والدفع عند الاستلام
4. طلباتي وتتبع حالة الطلب

تم تحديث إعدادات Android/Gradle لتجنب تعارض Flutter Gradle Plugin مع إعدادات Gradle القديمة، وإزالة evaluationDependsOn القديم من المشروع.

Package ID: com.zaden.app
